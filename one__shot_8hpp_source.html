6// one_shot<R(Args...)>: a small type-erased, move-only, call-consuming
7// callable box (design doc FD12, decision D-B). Chosen over
8// std::move_only_function because, at LLVM 23, libc++ does not declare
9// std::move_only_function at all -- not merely untagged by the feature-test
10// macro (ops/freer/handoffs/00-ground.handoff.md, DEV-S00-1) -- and libc++
11// is a row the CI matrix claims. FD12's decision rule therefore takes a
12// bespoke type uniformly, on every toolchain, rather than a macro-gated
13// fast path plus a bespoke fallback (strictly more surface than just the
14// fallback, which has to be written regardless).
15//
16// It mirrors Box's completeness-firewall role (box.hpp): the stored target
17// sits behind a type-erased pointer, so `one_shot<Box<X>(...)>` names a
18// complete type even while X is still incomplete at the point it is used
19// (impure_node<Op, X>, freer.hpp).
20//
21// Call-consumes, not merely move-only: operator()(Args...) && invokes the
22// target and destroys it as part of the same call. The type only offers an
23// rvalue-qualified call operator (the && makes one-shot-ness a type
24// property, exactly as FD3 does for the continuation's own && qualifier),
25// so a second call requires std::move-ing an already-emptied object --
26// caught by an assertion rather than silently dereferencing a null or
27// moved-from target.

90 /** Invoke the stored target and consume it -- the target is destroyed
91 * as part of this call whether or not it throws. Precondition: this
92 * one_shot currently holds a target (a default-constructed, moved-from,
93 * or already-called one_shot does not) -- asserted, so a violation is a
94 * hard, diagnosable error rather than a UB-adjacent null/moved-from
95 * call.
96 */
97 auto operator()(Args... args) && -> R {
98 assert(target_ != nullptr &&
99 "one_shot: call on an empty target (default-constructed, "
100 "moved-from, or already consumed by a previous call)");
101 concept_t *owned = std::exchange(target_, nullptr);
102 struct scope_delete {
103 concept_t *p;
104
105 ~scope_delete() { delete p; }
106 } cleanup{owned};
107 return owned->invoke(std::forward<Args>(args)...);
108 }

110 /** True iff this one_shot currently holds a target that has not yet
111 * been consumed by a call (or moved away).
