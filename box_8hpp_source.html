10/** Constexpr-capable owning pointer with deep-copy value semantics.
11 * Nullable (default ptr=nullptr), so it works in static_vector storage
12 * without wasteful default-allocations. Uses raw new/delete, which are
13 * constexpr in C++20+ for transient allocations.
14 *
15 * This is a workaround until consteval allocation lands in a future
16 * standard; std::indirect has the right semantics but its explicit
17 * default constructor blocks use in aggregate-initialised containers.
18 *
19 * @tparam A the wrapped type (typically a recursive Fix instantiation)
20 */
