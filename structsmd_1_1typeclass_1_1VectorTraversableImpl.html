Detailed Description

template<class VALUE_TYPE>
struct smd::typeclass::VectorTraversableImpl< VALUE_TYPE >

Traversable instance for std::vector. The primitive traverse sequences each element's effect via the supplied applicative, collecting the in-context element results into a vector while preserving the original element order and count.
