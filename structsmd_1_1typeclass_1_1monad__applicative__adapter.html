Detailed Description

template<class Impl>
struct smd::typeclass::monad_applicative_adapter< Impl >

Adapter: supplies pure (delegated to Impl) and synthesizes apply from bind + pure so a Monad can also serve as an Applicative base. ap mf mx = mf >>= \f -> mx >>= -> pure (f a)

constexpr (design D10, S14): apply was not marked constexpr before S14 (gana.t.cpp's ana_via_gana constexpr smoke test is the first caller to invoke join in a constant expression, via monad_typeclass<MSeed>.join(...) – generalized.hpp) – a pre-existing gap, not a new requirement; adding constexpr here is purely additive (Impl::bind/pure, which this forwards to, were already constexpr in every instance in this codebase).
