Overview

A field guide to the recursion-schemes menagerie, implemented in C++26 as the smd::fixpoint library: the full Kmett catalog — folds, unfolds, refolds, course-of-values recursion, Mendler style, Elgot algebras, and the comonadic/monadic generalizations — built on one fixpoint type, a constexpr Box, and typeclass objects. Every post transcludes the shipping code and a runnable example; every scheme is pinned by the degeneracy laws in its test file.
