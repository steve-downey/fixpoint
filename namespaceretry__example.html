◆ retry_attempt()

auto retry_example::retry_attempt ( int  attempt) -> RowFree
inline

One attempt: send the request; on success, the value is the reply's length; on failure, back off attempt seconds (SleepFor) and retry, up to three attempts total (1s after attempt 1, 2s after attempt 2). The value on total failure is -1; there is no fourth attempt. Composed with mbind + pure only (FD4): every continuation captures copyable state, so DEV-S05-1's move-only-continuation wall never bites here.
