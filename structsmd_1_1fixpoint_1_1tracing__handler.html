Detailed Description

template<class Handler>
struct smd::fixpoint::tracing_handler< Handler >

tracing_handler<Handler> / tracing(handler, log): wrap handler (an overloaded per-op callable set, or any callable set covering Sig) so every operation passed through it is first rendered into log (FD5), then delegated to handler for the response. log is a caller-owned trace&; the adaptor itself is a thin pass-through, cheap to build fresh per run_trace call. This is FD5's "first handler, first mock": the reference interpreter for observational testing.
