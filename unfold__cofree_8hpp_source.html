6// unfold_cofree: Cofree's ana half (design doc FD8, 2026-07-09 code-audit
7// correction) -- the recursion-schemes catalog never needed this: unfold_fix
8// (recursion_schemes.hpp) targets Fix<F> only, and histo's Cofree carrier
9// (cofree.hpp/histo.hpp) is built by *folding*, never unfolding. Mirrors
10// unfold_fix's lookup-based shape exactly, generalized from one coalgebra
11// S -> F<S> to a coalgebra PAIR (S -> B, S -> F<S>): `head_fn` supplies each
12// node's annotation, `coalgebra` supplies the next functor layer of child
13// seeds.
14//
15// Works for ANY functor F registered with functor_typeclass -- layer_fmap
16// dispatches through the same lookup every other scheme uses -- and this
17// header does not depend on the signature layer at all; freer_cosignature.hpp
18// (S06) builds the co-signature's Functor instance on top of this. See
19// freer_cosignature.t.cpp for a standalone proof against a pure-data functor
20// (NatF), independent of the co-signature's own (lazy) use.
21//
22// Termination is F's Functor instance's responsibility, not this function's
23// -- exactly as for unfold_fix. Over an EAGER F (a pure-data functor whose
24// fmap invokes its callable immediately -- NatF, IntListF), the coalgebra
25// must reach a terminal layer (one contributing no recursive-position seeds)
26// or this diverges. Over a LAZY F (freer_cosignature.hpp's co-signature,
27// whose fmap post-composes onto a stored responder WITHOUT invoking it),
28// unfold_cofree always terminates after building exactly one node, no matter
29// what the coalgebra does: layer_fmap never recurses into the next seed
30// until a responder is actually invoked at runtime, and that invocation
31// happens outside this function entirely. That laziness is the entire
32// reason the co-signature's Functor instance is shaped the way it is (FD8).
33//
34// Capture-ownership rule (FD4) applies to the recursive closure below just
35// as it does to every closure handed to layer_fmap: `head_fn`/`coalgebra`
36// are captured BY VALUE, never by reference. This is not optional even
37// though unfold_cofree's own parameters are local to this call: for a LAZY
38// F, layer_fmap does not invoke the closure synchronously -- it stores it,
39// unevaluated, inside the returned layer, which this function then returns
40// to ITS caller. By the time anything actually invokes that stored closure
41// (typically much later, e.g. via a Cofree tail's responder), this
42// function's own stack frame is long gone. A `[&]`-capturing version of
43// this closure was verified by hand to fail exactly this way: built as a
44// standalone probe pairing a lazy CoSigLayer-shaped functor with STATEFUL
45// (not stateless) head_fn/coalgebra closures (a stateless closure makes a
46// dangling reference invisible to Asan -- the same lesson S02-S05 record),
47// `g++-16 -fsanitize=address` reported a `stack-use-after-return` at the
48// exact line reading the dangling `head_fn` capture; switching the capture
49// to by-value fixed it, both compilers, same probe. For an EAGER F this
50// distinction is invisible (the closure runs synchronously, so `[&]` would
51// have been safe there too) -- capturing by value costs nothing correctness
52// -wise for the eager case and is required for the lazy one, so it is the
53// only spelling used here.

64/** unfold_cofree<F>(head_fn, coalgebra, seed) -> Cofree<F, B>, where
65 * B = the result type of head_fn(seed). Builds one Cofree node per step:
66 * `head_fn` (S -> B) annotates the node; `coalgebra` (S -> F<S>) supplies
67 * the next functor layer of child seeds, expanded via layer_fmap
68 * (functor_typeclass lookup) into a layer of child Cofree trees.
69 *
70 * Explicit (not deduced) trailing return type: directly self-recursive
71 * through the nested lambda handed to layer_fmap -- a deduced `auto` return
72 * type cannot be used before its own deduction completes, even one level
73 * down inside a lambda (same reasoning as CofreeFunctorImpl::fmap,
74 * cofree.hpp, and FreeMonadImpl::bind, free.hpp).
75 */
76template <template <class> class F, class HeadFn, class Coalgebra, class Seed>
77constexpr auto unfold_cofree(HeadFn head_fn, Coalgebra coalgebra,
78 const Seed &seed)
79 -> Cofree<F,
80 std::remove_cvref_t<std::invoke_result_t<HeadFn, const Seed &>>> {
81 using B = std::remove_cvref_t<std::invoke_result_t<HeadFn, const Seed &>>;
82 auto layer = coalgebra(seed);
83 auto expanded = layer_fmap(
84 [head_fn, coalgebra](const Seed &child) -> Cofree<F, B> {
85 return unfold_cofree<F>(head_fn, coalgebra, child);
86 },
87 std::move(layer));
88 return Cofree<F, B>{std::invoke(head_fn, seed), std::move(expanded)};
89}
