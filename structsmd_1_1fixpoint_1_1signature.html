Detailed Description

template<operation... Ops>
struct smd::fixpoint::signature< Ops >

signature<Ops...>: a closed effect signature. Its nested member template type is the layer functor handed to Free – the closed-world Coyoneda of the signature.

A member template rather than an alias template: alias templates as template-template arguments sit on P0522 matching, where GCC and Clang still diverge in practice; the nested class template is the portable spelling (FD3).

coyoneda_signature/coyoneda_value_type are the nested typedefs FD11's decision (D-A) requires: they let the generic Functor instance recover, from the layer type alone, the owning signature and the recursive position it needs to build the mapped layer's result type. coyoneda_signature is deliberately signature-specific (not a generic name like "recursive_position") so the constrained specialization it keys never overlaps the Free<F,A> specialization or any pure-data functor instance in the library.
