6// The sender/receiver interpreter for Freer<Sig, A> (design doc Section 5
7// forward reference; FD4, FD5). Where freer_run.hpp's `run` drives a
8// program to completion synchronously, `run_task` interprets it into a
9// beman::execution coroutine -- `beman::task<A>` is the Mendler algebra's
10// monomorphic carrier, the C++ image of the interpreter's quantified answer
11// type. Each operation is mapped, by a handler, to a sender whose value
12// completion is that operation's response; run_task co_awaits the sender,
13// resumes the suspended one-shot continuation with the response, and
14// recurses on the rest of the program.
15//
16// This is the ONE header in the module that depends on beman::execution /
17// beman::task; the core fold it drives (mcata_free.hpp) has no beman in it,
18// and its test links the beman targets in a dedicated executable
19// (freer_task.t.cpp), never smd_fixpoint_test or fixpoint.fixpoint (S07d).
20//
21// SHAPE THAT LANDED: run_task IS mcata_free at Result = beman::task<A> --
22// the design's Section 5 claim as running code, not a hand-written loop.
23// The impure-layer algebra (run_task_step) is a coroutine, so interpreting
24// an N-effect program stacks N task frames, each suspended awaiting the
25// next (frame-per-effect). That is FD6's disclosed demo-scale cost (Box per
26// resumption + one coroutine frame per effect), acceptable for the retry
27// example; a single-coroutine resume-into-a-loop rewrite (mirroring `run`)
28// is the available FD6 optimization if a later step needs O(1) live frames.
29//
30// COROUTINE CAPTURE-OWNERSHIP (FD4, in coroutine clothing). The one-shot
31// continuation is move-only and consumed on resumption (FD4); a coroutine
32// that resumes it must OWN it across the suspension, never borrow it from an
33// enclosing native stack frame that may already be gone. Two rules make
34// that hold, and both are load-bearing (violating either is an Asan
35// use-after-free, not a compile error):
36// 1. Every coroutine here takes the state it touches after a suspension
37// point BY VALUE (handler, recurse, the layer, the node) -- a
38// by-value coroutine parameter is copied/moved into the frame before
39// the body runs; a reference parameter is NOT, and dangles past the
40// first suspend (beman::task's initial_suspend is suspend_always, so
41// the body does not even begin until after the producing full-
42// expression has ended and its temporaries are gone).
43// 2. The Mendler algebra handed to mcata_free (task_phi) is a NON-
44// coroutine thin forwarder. A coroutine *lambda* would store the
45// handler in its closure, and that closure is a temporary destroyed
46// at the end of the full-expression that created the task -- while the
47// task stays suspended referencing it. task_phi forwards synchronously
48// into run_task_step, which owns handler by value; the closure's job
49// is done before the first suspension.

69/** task_handler_for<Handler, Op>: `Handler` maps operation `Op` to a
70 * beman::execution sender. The handler-as-adaptor of the S/R interpreter:
71 * `handler(op)` is a sender whose *value completion carries `Op::response`*
72 * -- the contract the async model replaces `run`'s synchronous
73 * `handler(op) -> Op::response` with. The value-type half of the contract
74 * (the completion is exactly `Op::response`) is enforced structurally at
75 * the resumption site in `resume_one` -- `typename Op::response response =
76 * co_await handler(op);` -- so this concept keys only on "is a sender",
77 * keeping it free of beman's completion-signature/env detail machinery
78 * while still rejecting a plainly non-sender handler with a readable
79 * message at the `run_task` call.
80 */
81template <class Handler, class Op>
82concept task_handler_for =
83 operation<Op> && std::invocable<Handler &, Op> &&
84 beman::execution::sender<std::invoke_result_t<Handler &, Op>>;

88/** resume_one: the resumption path for one suspended operation. co_await the
89 * handler's sender for the response, then invoke the move-only one-shot
90 * continuation on that response -- as an rvalue, exactly once (one_shot's
91 * `operator()(...) &&`), on this (the coroutine's) resumption path -- and
92 * unbox its Box<X> result.
93 *
94 * `node` is taken BY VALUE so the frame owns it -- and therefore owns
95 * `node.k` (the move-only one_shot) -- across the co_await suspension (FD4).
96 * `handler` is a reference to the caller frame (run_task_step), which is
97 * itself suspended awaiting this task, so it outlives every suspension here.
98 * Templated per Op so std::visit's alternatives all yield the SAME task<X>.
99 */
100template <class X, class Handler, operation Op>
101auto resume_one(Handler &handler, impure_node<Op, X> node)
102 -> beman::execution::task<X> {
103 static_assert(task_handler_for<Handler, Op>,
104 "run_task: handler does not map every operation in Sig to "
105 "a sender -- see the impure_node<Op, X> named in the "
106 "instantiation backtrace for which Op");
107 typename Op::response response = co_await std::invoke(handler, node.op);
108 co_return *std::move(node.k)(std::move(response));
109}

111/** run_task_step: the Mendler algebra's impure-layer (Roll) case, as a
112 * coroutine. Visits the single suspended node, resumes it (resume_one), then
113 * recurses on the unboxed rest via `recurse` (mcata_free partially applied).
114 *
115 * `handler` and `recurse` are taken BY VALUE -- owned by this frame across
116 * every suspension (FD4 capture-ownership rule in coroutine clothing:
117 * nothing this coroutine touches after a suspend is borrowed from an
118 * enclosing native frame). `layer` is likewise by value; the visited node is
119 * moved out of it into resume_one.
120 */
121template <class Sig, class A, class Handler, class Recurse>
122auto run_task_step(Handler handler, Recurse recurse,
123 typename Sig::template type<Freer<Sig, A>> layer)
124 -> beman::execution::task<A> {
125 using X = Freer<Sig, A>;
126 X next = co_await std::visit(
127 [&handler]<operation Op>(
128 impure_node<Op, X> &&node) -> beman::execution::task<X> {
129 return detail::resume_one<X, Handler, Op>(handler, std::move(node));
130 },
131 std::move(layer.node));
132 co_return co_await std::move(recurse)(std::move(next));
133}

135/** task_phi: the Mendler algebra handed to mcata_free for the Roll case. A
136 * NON-coroutine thin forwarder (see this header's top comment, rule 2): its
137 * closure holds `handler` only long enough to copy it, synchronously, into
138 * run_task_step's frame. Making phi a coroutine lambda would dangle the
139 * captured handler past the first suspension.
140 */
141template <class Sig, class A, class Handler>
142struct task_phi {
143 Handler handler;
144
145 template <class Recurse>
146 auto operator()(Recurse recurse,
147 typename Sig::template type<Freer<Sig, A>> layer) const
148 -> beman::execution::task<A> {
149 return detail::run_task_step<Sig, A, Handler, Recurse>(
150 handler, std::move(recurse), std::move(layer));
151 }
152};
153
154} // namespace detail

156/** run_task<Sig, A>(handler, prog) -> beman::task<A>: interpret a
157 * Freer<Sig, A> program into a beman::execution coroutine against `handler`
158 * (a callable set covering every operation in `Sig` -- an `overloaded` of
159 * one lambda per Op, each returning a sender-of-response, is the intended
160 * shape; a row is covered by a handler set spanning all its member
161 * signatures, exactly like `run`). This IS mcata_free at Result =
162 * beman::task<A>: Pure a -> co_return a; a Roll layer -> co_await the op's
163 * sender, resume the one-shot continuation with the response, recurse on the
164 * unboxed rest.
165 *
166 * `handler` and `prog` are taken BY VALUE: the whole interpretation is a
167 * coroutine that must own everything it touches after a suspension point
168 * (FD4). The handler must therefore be copyable, and any mutable state it
169 * scripts (a call counter, virtual-clock cursor) must be shared by
170 * reference/pointer capture so every copy observes it -- the ordinary way to
171 * write a scripted mock, and what `run`'s handlers already do.
172 *
173 * Sig and A must be given explicitly (the S04 deduction limitation:
174 * Freer<Sig,A> is an alias `Free<Sig::type, A>`, which deduction cannot
175 * invert). Handler deduces from the argument.
176 */
177template <class Sig, class A, class Handler>
178auto run_task(Handler handler, Freer<Sig, A> prog)
179 -> beman::execution::task<A> {
180 return mcata_free<beman::execution::task<A>, Sig::template type, A>(
181 [](A a) -> beman::execution::task<A> { co_return std::move(a); },
182 detail::task_phi<Sig, A, std::remove_cvref_t<Handler>>{
183 std::move(handler)},
184 std::move(prog));
185}
