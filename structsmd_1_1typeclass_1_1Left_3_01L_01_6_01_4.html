Detailed Description

template<class L>
struct smd::typeclass::Left< L & >

Reference-side specialization: Left<L&> holds a pointer to the referent (P2988 model), not a real reference member, so that assignment can rebind rather than being deleted (a struct with a true reference member has no assignment operator). Binds lvalues only: the L&& constructor is deleted so a temporary can never be bound and then dangle. Copy/assign rebind the pointer (shallow: the wrapper's own constness only ever protects the pointer, never the referent — a const Left<L&> still yields a mutable L& via referent(), exactly like a const pointer variable still permitting mutation through it).
