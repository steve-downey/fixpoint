Detailed Description

template<class VALUE_TYPE>
struct smd::typeclass::TestIdentityTraversableImpl< VALUE_TYPE >

Traversable implementation for the public Identity<V> (smd/typeclass/ identity.hpp). Test-only: there is no general Traversable typeclass instance for Identity in the library proper, only here, since traversing an effect-free context is a law-testing convenience, not a scheme need.
